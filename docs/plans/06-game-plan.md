# 06. Game Plan, Playbook, veto, Briefing

> Item-ийн ID: `GP-…`. Нэр томъёо: Game Plan, Fixture, Playbook, Lever, Caution, Setup, Set play, Self-scout, Briefing, Forecast (`CONTEXT.md`). Холбоотой: `03` (Forecast, veto), `05` (багийн статистик), `01` WS-5 (Briefing).

## Зорилго

Өрсөлдөгч бүрийн эсрэг **богино, шууд хэрэглэхэд бэлэн** төлөвлөгөө гаргах:

- Map бүрт нэг хуудас, timeout card, Map хоорондын хуудас.
- Тоглолтоос 1–2 хоногийн өмнө бэлэн байх. Тоглолтын өдөр 15–30 минутын давталт.

Учир нь coach-ийн тоглолтын үеэр нөлөөлөх боломж маш цөөн: warmup, хагас, 3 tactical timeout (Valve-ийн дүрэм, `12-research-sources.md`). Online тоглолтод бүр хэлэх боломжгүй. Төлөвлөгөөг coach болон IGL эзэмшдэг. Баримт нь "товч, bullet-тэй, GIF-тэй, бага нь илүү" байх ёстой.

## Одоогийн байдал (кодын аудит, 2026-10-21)

**12 tab, 3 бүлэгт:**

- Decision, Verdict, Metrics, Head-to-head
- Maps, Players, Duels, Roles, Edge
- Heatmaps, Movement, Юу хийх

Хуудас бусад tab-ыг ар талд нь нэг нэгээр нь бэлдэж, nav дээр бэлэн болсныг тэмдэглэдэг.

**Playbook:** Map бүрийн habit Evidence strength, Replay-ийн ref-тэй. Lever, Caution (Review-ээс). Юу хийх жагсаалт: veto-ийн мөрүүдийн дараа pick/contest Map бүрийн эхний Lever, Caution.

**Алдаанууд:**

- **Decision:**
  - Хэвлэх өгүүлбэр буруу: 12/12 давуу үед ч «цаасан дээр тэнцүү» гэж бичдэг (`decision.py:144-148`).
  - Weakness байхгүй үед хамгийн муу үзүүлэлтийг «багийн сул тал» гэж бичдэг (`191-211`).
  - `_levers` манай өөрийн эмзэг байдлыг ч "Lever" гэж тоолдог (`73-113`).
- **Тоо:**
  - Linchpin бол noise.
  - Pistol overtime-ийг тоолдог.
  - Head-to-head delta-ийн нэгж буруу.
  - Metrics-ийн график ADR, харьцаа, хувийг нэг 0–100 тэнхлэгт зурдаг (`gameplan_view.py:192-214`).
- **Текст:**
  - Caption кодтой зөрдөг (`panels.tsx:238,252,535,778`).
  - Англи `why` өгүүлбэр монгол текстэд холилддог (`decision.py:287`, `mn.py:596-601`). График бүгд англи.
- **Movement:** `scene.ts:309` бүх тоглогчийн харагдацад хоёр тоглогчид ижил walk оноодог.
- **Гүйцэтгэл:**
  - Нийтлэг stamp: аль нэг parse эсвэл Review rebuild бүх Fixture-ийн cache-ийг хүчингүй болгодог.
  - `Report` хүсэлт бүрт дахин бүтээгддэг.
  - `pool_cache` lock-ийг 180 s хүртэл хүлээдэг. Энэ нь Cloudflare-ийн 100 s-ийн хязгаараас урт.
  - Grid-ийн cell cache-лэгддэггүй.
- **Хуваалцах:**
  - Export, print (`@media print` байхгүй), хуваалцах арга байхгүй.
  - Maps, Players, heatmap-ийн сонголт URL-д ордоггүй.
  - Хуудас 1024px-ээр хязгаарлагдсан.
- **Агуулга:**
  - Habit-ийг base rate-тай шалгадаггүй (TM-4).
  - Recency, roster-ийн жин байхгүй (TM-3).
  - 40 s-ээс цааш шинжилдэггүй (TM-7).
  - Buy type-аар шүүдэггүй.
