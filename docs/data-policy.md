# Датаны бодлого

> Хуулийн зөвлөгөө биш. Эх сурвалж бүрийн нөхцөлийг 2026-10-21-нд шалгасан (`docs/plans/12-research-sources.md`, §5). Нөхцөл өөрчлөгдвөл энэ хуудсыг шинэчилнэ.

## Зарчим

cs-analyze бол нэг клубын дотоод хэрэгсэл (ADR 0011). Бусдаас авсан датаг дотооддоо анализ хийхэд л хэрэглэнэ. Хэнд ч дамжуулахгүй, нийтэд гаргахгүй.

## Эх сурвалж бүрээр

| Эх | Нөхцөл | Бидний дүрэм |
|---|---|---|
| HLTV | API байхгүй, Cloudflare-ийн цаана. Нөхцөлд "лицензгүйгээр бизнесийн зорилгоор ашиглахгүй" гэсэн заалт бий (хайлтын хуулбараас уншсан) | Нэг Chromium, хуудас хооронд ≥1.5 s (`browser.py`). Demo-г parse хийсний дараа устгана. HLTV-ийн дата, demo-г гадагш тараахгүй. Олон клубт нээх үед (WS) лицензийн асуудлыг дахин авч үзнэ |
| Valve VRS repo | GitHub-д нээлттэй, LICENSE файлгүй. Дата нь "provided by HLTV.org" | Rating-ийн prior болон шалгалтад дотооддоо ашиглана. Дахин нийтлэхгүй |
| Liquipedia | Зөвхөн MediaWiki API. Хүсэлт ≤1/2 s (`parse` ≤1/30 s), тодорхой User-Agent, CC-BY-SA 3.0. HTML scraping хориотой | API-аар л уншина. Хуудсанд харуулбал эх сурвалжийг нь заана |
| FACEIT | Data API-д key хэрэгтэй. Demo татахад Downloads API-ийн тусгай зөвшөөрөл хэрэгтэй | Зөвшөөрөл авахаас өмнө demo татахгүй. Тоглогчийн pug-ийг зөвхөн тэр тоглогчийн зөвшөөрөлтэй |
| Premier / matchmaking | Share code нэг сарын дотор хүчинтэй. Тоглогч бүрийн authentication code шаардана | Зөвхөн өөрийн тоглогчдоос, тэдний зөвшөөрөлтэй |

## Хувийн мэдээлэл

- Demo болон Tick Data-д Steam id, нэр, тоглогч бүрийн зан төлөвийн дэлгэрэнгүй (байрлал, онолт, алдаа) хадгалагддаг. Тиймээс хандалтыг зөвхөн урилгаар олгоно (Staff урина).
- Монголын хувийн мэдээллийн хамгаалалтын хууль (2022 оноос мөрдөгдөж буй) үйлчилнэ. ЕХ-д амьдардаг тоглогчийн датанд GDPR (3(2)(b)) хамаарч болно.
- Тоглогчийн Development plan ба performance coach-ийн тэмдэглэл бол хамгийн хувийн дата. Зөвхөн Staff болон тухайн тоглогч хардаг.
- Тоглогч багаас гарвал түүний хувийн тэмдэглэл, Development plan-ийг устгах хүсэлтийг биелүүлнэ. Тоглолтын дата (Match Map) үлдэнэ.

## Integrity

Staff болон тоглогчид бооцоо тавих нь integrity-ийн дүрмээр хориотой. Апп bookmaker-ийн odds-ыг харуулахгүй. Хэрэв FC-10-ийг хийвэл odds зөвхөн model-ийн нарийвчлалыг үнэлэх benchmark болно.
